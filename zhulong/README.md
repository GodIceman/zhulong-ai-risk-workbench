# 烛龙 AI 内容风险分析工作台

这是一个面向作品集演示的本地 Vue 工作台。当前主链路聚焦三项能力：

- 图片 AI 生成风险筛查
- 完整 AI 生视频与人脸换脸联合鉴伪
- 中文 AI 写作风格检测

系统强调风险信号、能力边界与人工复核，不提供通用“真假鉴定”。

主界面对话框是统一检测入口：直接粘贴文字会自动调用中文文字模型；通过对话框上传或拖入图片、视频时，前端会识别文件类型并自动路由到对应模型。下方快捷入口仍保留预览和手动确认流程。

## 能力范围

| 模块 | 当前支持 | 明确不支持 |
| --- | --- | --- |
| 图片 | 固定版本 DDA + Community Forensics 双模型、生成元数据、EXIF 与来源线索、证据不足时弃权 | 局部编辑、重绘、拼接和篡改区域定位；发布级真伪认证 |
| 视频 | AEGIS + D3 完整生成共识、LNCLIP 换脸信号、采样帧时间轴 | 证明视频真实、D3 单独定性、司法鉴定或商业发布 |
| 文字 | 固定版本中文 BERT、代表性分段、重点段落、采样覆盖率、正文 SHA-256 指纹、离线声明/来源清单 | 作者身份认证、抄袭判断、联网事实核查、发布级结论 |

视频分支采用阳性专用策略：完整生成必须同时满足 AEGIS 强信号和 D3 超保守时序门槛；
换脸由 LNCLIP 独立判断。未达到阈值一律弃权，不输出“视频真实”，D3 不能独立改变结论。

图片分支优先使用 CUDA：DDA 提供主信号，Community Forensics 提供独立辅助信号。没有明确生成元数据时，两者都越过本地校准的强阈值才输出高风险 AI 结论；模型冲突、截图/游戏域和来源冲突返回“不确定”。当前仅在 62 张小型本地回归集上验证，不能外推为生产准确率。

## 文字检测方案

文字服务使用固定 revision 的
`AnxForever/chinese-ai-detector-bert`，在本机 CPU 上运行。长文会切成代表性段落，
分别推理后按有效字符数加权聚合；只有全文分数和强信号段落比例同时达到阈值时，
并且至少有两个独立段落时，才显示“疑似 AI 写作风格”。单段、混合或边界结果
会返回“不确定”。

报告中的分数表示该模型下的写作风格信号，不是“由 AI 创作的客观概率”。

## 启动

推荐在项目根目录执行：

```bat
start.bat
```

也可以在当前 `zhulong` 目录执行：

```bat
npm run dev
```

两种方式都会启动模型服务和前端。默认地址：

```text
http://127.0.0.1:3000/#/login
```

## 本地服务

| 服务 | 默认地址 |
| --- | --- |
| 前端 | `127.0.0.1:3000` |
| 统一内容 API | `127.0.0.1:5002` |
| 视频联合鉴伪服务 | `127.0.0.1:5003` |
| 图片与文字模型服务 | `127.0.0.1:5004` |

所有服务默认只绑定 `127.0.0.1`，不直接向局域网或公网开放。

常用健康检查：

```text
http://127.0.0.1:5002/api/health
http://127.0.0.1:5003/api/video/health
http://127.0.0.1:5004/api/text/health
```

## 隐私与安全默认值

- 风险报告默认只保存在统一 API 进程内存中，重启后不可恢复。
- 只有显式设置 `PERSIST_REPORTS=true`，报告才会写入 `logs/reports/`。
- 图片和视频文件处理完成后会删除临时副本。
- 文章正文默认只在任务内存中处理；报告保留必要片段、来源清单和正文哈希。
- 用户填写的来源声明是不可信上下文，不能把素材升级为“真实”。
- 模型输出均标记为实验性，不应作为处罚、审核或法律结论的唯一依据。
- AEGIS 与 D3 均存在域偏移风险，完整生成分支只适合本地作品集演示。
- WaveRep G4 已经实测但因本地真人误报过高被排除出运行时决策链。
